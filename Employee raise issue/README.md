# Employee Raise Issue

## Project Overview

Employee Raise Issue is a ServiceNow application that allows employees to submit and track workplace issues such as network, software, hardware, and access problems.

## Features

- Easy issue submission
- Issue tracking
- Category and subcategory selection
- State tracking
- Short description
- Employee Center integration
